# Imagens de Produtos

As dez pastas usam os títulos dos cartões de Produtos. Escrita e escritório
foram reunidos em «Papelaria, escritório e escrita». Os ficheiros originais
foram preservados.

As cinco novas áreas usam agora os ficheiros locais acrescentados às respetivas
pastas. Os cartões mostram manta, cadeira dobrável, porta-cartões, ferramenta
dobrável e caixa de apresentação. Os guias incluem outras imagens úteis. São
ilustrações; não comprovam materiais, proteção, homologação ou desempenho.
Não foram criadas nem procuradas fotografias externas.

`visuais/` conserva as cópias públicas com nomes neutros usadas pelo site.
Não renomear essa pasta: é preparada pelo gerador. A seleção está em
`conteudos/produtos_imagens.py`, no mapa `IMAGENS` das onze famílias/Guias.
Execute `python gerar.py --secao produtos` depois de alterar a seleção.
Os créditos existentes mantêm-se; uma cópia não altera a autoria ou a licença.
